📋 Comment créer vos tables sur Supabase ?

  1. Rendez-vous sur votre tableau de bord Supabase.
  2. Allez dans le menu SQL Editor à gauche.
  3. Cliquez sur New query.
  4. Copiez et collez le contenu du fichier supabase_schema.sql généré dans votre projet.
  5. Cliquez sur Run pour créer les tables automatiquement.
